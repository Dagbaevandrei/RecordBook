# RecordBook (Зачетная книжка студента)

Модель зачетной книжки на C# (.NET 8).

## Функционал
- Загрузка данных из `input.json`
- Сохранение данных в `output.xml`
- CRUD-операции для преподавателей, оценок (экзамены/зачеты), курсовых и дипломной работы
- Сортировка и фильтрация по любым полям

## Запуск
```bash
dotnet run
```
